# 설계 결정 기록

최신순. 기존 결정 수정 시 "→ 이후 변경" 링크 추가, 삭제 금지.

---

## 2026-11-04 — 기기정보 수집 구조

**결정**: `Device` 별도 테이블로 분리, `users.pushToken` deprecated 예정.

**이유**: 한 유저가 여러 기기를 사용하거나 기기를 교체할 경우 단일 필드로 대응 불가.
FCM 토큰은 앱 실행 시마다 갱신되므로 `upsert` 방식으로 관리.

**관련 문서**: [data/device.md](../data/device.md)

---

## 2026-11-04 — 어드민 DB 공유

**결정**: crew-admin은 crew-api와 **같은 PostgreSQL DB**를 공유.

**이유**: 어드민은 동일 데이터를 읽고 수정하는 인터페이스일 뿐. 별도 DB는 동기화 문제만 생김.
crew-api의 `/api/admin/*` 엔드포인트를 통해 접근. 직접 DB 연결 없음.

---

## 2026-11-04 — 어드민 인증 방식

**결정**: `admin_session` 쿠키 + 환경변수 `ADMIN_SECRET` 비교 방식.

**이유**: 초기 단계, 어드민 계정은 단일 비밀번호. 다중 계정 필요 시 별도 `Admin` 테이블로 전환 예정.

**완료 기준 미달 시**: `Admin` 테이블 + bcrypt 해시 방식으로 전환.
