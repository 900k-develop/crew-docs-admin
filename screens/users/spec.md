# 유저 관리 스펙

- 경로: `/users`
- 구현 파일: `src/ui/screens/UsersScreen.tsx`
- 관련 API: [api/users.md](../../api/users.md)

## 1. 목적

전체 유저 목록 조회, 검색, 상세 보기, 활동 제한/해제.

## 2. UI 구성

| 영역 | 설명 |
|---|---|
| 검색창 | 이름 · 전화번호 검색 |
| 테이블 | 이름 · 전화번호 · 동네 · 매너점수 · 가입일 · 상태 · 액션 |
| 슬라이드 패널 | 행 클릭 시 오른쪽에서 슬라이드 오픈 |
| 페이지네이션 | 페이지 단위 (PAGE_SIZE: 20) |

### 슬라이드 패널

- 열리는 조건: 테이블 행 클릭
- 패널 내용:
  - 기본 정보 (이름, 전화번호, 동네, 매너점수, 가입일)
  - 통계 (참여 번개 수, 개설 번개 수, 노쇼 횟수)
  - 제한 상태 (`restrictedUntil` 표시)
  - 기기 정보 목록 (추가 예정 — [data/device.md](../../data/device.md))
- 액션:
  - 활동 제한 (기간 선택: 1일/3일/7일/30일)
  - 제한 해제

## 3. API 호출

| 액션 | 메서드 | 엔드포인트 | 비고 |
|---|---|---|---|
| 목록 조회 | GET | `/api/admin/users?page=&q=` | |
| 상세 조회 | GET | `/api/admin/users/:id` | 기기 정보 포함 예정 |
| 제한 설정 | PATCH | `/api/admin/users/:id` | `{ restrictedUntil }` |

## 4. 상태 · 필터

- 검색: 이름, 전화번호 (서버사이드)
- 정렬: 가입일 최신순 (고정)
- 페이지네이션: 20건/페이지
