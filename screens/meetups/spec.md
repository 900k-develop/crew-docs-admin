# Meetups 스펙

- 경로: `/meetups`
- 구현 파일: `src/ui/screens/UmeetupsScreen.tsx`

## 1. 목적

전체 번개 목록 조회·검색, 상태 강제 변경, 직접 수정, 채팅 메시지 접근.

## 2. UI 구성

| 영역 | 설명 |
|---|---|
| 검색창 | 제목·장소 검색 |
| 테이블 | 제목 · 호스트 · 상태 · 날짜 · 장소 · 참여/정원 · 생성일 |
| 슬라이드 패널 | 행 클릭 시 오른쪽에서 슬라이드 오픈 |
| 페이지네이션 | 페이지 단위 (PAGE_SIZE: 20) |

### 슬라이드 패널

- 기본 정보 (제목, 호스트, 상태, 날짜, 장소, 참여/정원)
- 편집 폼: 제목·장소·날짜 직접 수정 (운영 목적, 참가자 알림 미발송)
- 상태 강제 변경: CANCELED 처리
- 채팅 보기 버튼 → 채팅 메시지 화면으로 이동

## 3. API 호출

| 액션 | 메서드 | 엔드포인트 | 비고 |
|---|---|---|---|
| 목록 조회 | GET | `/api/admin/meetups?page=&q=` | |
| 상태 변경 | PATCH | `/api/admin/meetups/:id` | `{ status: "CANCELED" }` |
| 직접 수정 | PATCH | `/api/admin/meetups/:id` | `{ title?, placeName?, startAt? }` — **신규 필드** |
