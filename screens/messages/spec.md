# 채팅 메시지 관리 스펙

- 경로: `/meetups/:id/messages`
- 구현 파일: `src/ui/screens/MessagesScreen.tsx`

## 1. 목적

특정 번개·크루 채팅방의 메시지 목록 확인 및 문제 메시지 강제 삭제.
신고 처리 화면에서 연결되거나 번개/크루 상세 슬라이드 패널에서 진입.

## 2. UI 구성

| 영역 | 설명 |
|---|---|
| 헤더 | 번개/크루 제목, 뒤로가기 |
| 메시지 목록 | 발신자 · 내용 · 시각 · 삭제 버튼 (SYSTEM 메시지는 삭제 버튼 없음) |
| 삭제 확인 | 삭제 전 "복구 불가" 확인 모달 |

## 3. API 호출

| 액션 | 메서드 | 엔드포인트 | 비고 |
|---|---|---|---|
| 메시지 목록 | GET | `/api/admin/meetups/:id/messages` | **신규 API** — 최대 200개 |
| 메시지 삭제 | DELETE | `/api/admin/messages/:messageId` | **신규 API** |

## 4. 완료 기준

- [ ] 메시지 목록 조회
- [ ] 삭제 버튼 (SYSTEM 제외)
- [ ] 삭제 확인 모달
- [ ] 삭제 후 목록 갱신
- [ ] 에러 상태 처리
