# <그룹명> API

베이스 경로: `/api/admin/<그룹>`

인증: `admin_session` 쿠키 필요 (없으면 401)

## 엔드포인트 목록

### GET /<그룹>

목록 조회.

**쿼리 파라미터**

| 파라미터 | 타입 | 필수 | 설명 |
|---|---|---|---|
| page | number | N | 기본값 1 |
| q | string | N | 검색어 |

**응답**

```json
{
  "<그룹>": [],
  "total": 0
}
```

---

### GET /<그룹>/:id

단건 조회.

**응답**

```json
{}
```

---

### PATCH /<그룹>/:id

수정.

**요청 바디**

```json
{}
```

**응답**

```json
{ "ok": true }
```

## 에러 코드

| 코드 | 상태 | 의미 |
|---|---|---|
| unauthorized | 401 | 세션 없음 |
| not_found | 404 | 대상 없음 |
